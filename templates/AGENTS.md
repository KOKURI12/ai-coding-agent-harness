# AGENTS.md

## 共通ルール

このプロジェクトでは、以下のルールを守って作業してください。

## 回答ルール

- 回答・説明は日本語で行うこと。
- 作業前に、まず関連ファイルを確認すること。
- コード修正前に、変更方針を簡潔に説明すること。
- 依頼内容に必要な最小限の修正だけを行うこと。
- 無関係なリファクタリングは行わないこと。
- 既存機能を壊さないことを優先すること。

## セキュリティルール

以下のファイル・情報を読まない、表示しない、変更しないこと。

- `.env`
- `.env.*`
- AWS 認証情報
- API キー
- シークレットキー
- token
- `.pem`
- `.key`
- credentials 系ファイル
- secrets ディレクトリ

## 禁止操作

以下の操作は事前確認なしに実行しないこと。

- npm パッケージの追加
- DB 削除
- AWS リソース変更
- IAM 権限変更
- `git push`
- `git reset --hard`
- `rm -rf`
- 本番環境へのデプロイ

## 推奨作業フロー

1. `PROJECT_CONTEXT.md` を確認する
2. 関連ファイルを確認する
3. 変更方針を説明する
4. 必要最小限の修正を行う
5. 確認コマンドを実行する
6. 変更内容・確認結果・懸念点をまとめる

## 確認コマンド

プロジェクトに存在する場合、以下を確認してください。

- npm run lint
- npm test
- npm run build
- git diff
- git status
